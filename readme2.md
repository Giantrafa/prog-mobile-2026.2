# 📱 Expo-01

Projeto desenvolvido para a disciplina **Programação para Dispositivos Móveis**, utilizando **React Native, Expo e EAS**.

---

## 🚀 Para Rodar

### 1. Entrar na pasta do projeto

```bash
cd expo-01

2. Rodar o projeto

npm run goTunnel

3. Abrir no celular

Após iniciar o projeto, será exibido um QR Code no terminal.

Abra o Expo Go no celular e escaneie o QR Code.
💻 Para Rodar em Qualquer Computador
1. Clonar o repositório

git clone URL_DO_REPOSITORIO

2. Entrar na pasta do projeto

cd expo-01

3. Instalar as dependências

npm install

4. Rodar o projeto

npm run goTunnel

Depois, escaneie o QR Code usando o Expo Go.
⚙️ Configuração Inicial
1. Login no EAS

eas login

Verificar a conta autenticada:

eas whoami

2. Criar o projeto EAS

eas init

Projeto criado:

@unicap-nova/expo-01

3. Configurar o EAS Build

eas build:configure

4. Instalar o Expo Dev Client

npx expo install expo-dev-client

5. Configurar o EAS Update

eas update:configure

6. Publicar uma atualização

eas update --auto
